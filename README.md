# 📊 简易盯盘台 Pro

轻量、开源的智能价格异动盯盘助手。纯前端原生实现，**无需后端、无需构建、无需安装任何依赖**，打开浏览器即可使用。

---

## ✨ 功能特性

### 行情引擎
- **多源聚合**：腾讯财经为主源，东方财富为备源，自动故障切换
- **品类自动识别**：A股 / 指数 / ETF / 转债 / 场外基金，正确处理场内外基金号段重叠问题
- **真实交易日历**：以指数日K线反推交易日，自动识别国庆春节等法定休市日，避免节假日空转
- **量纲统一校准**：成交量按「手→股」、成交额按「万元→元」换算，以「均价≈现价」交叉验证

### 提醒能力（5 类）

| 类型 | 说明 |
|------|------|
| 价格提醒 | 向上突破 / 向下跌破 |
| 区间提醒 | 进入 / 离开指定价格区间 |
| 涨跌幅提醒 | 涨幅或跌幅达到阈值 |
| 量比异动 | 当日成交量相对近期的放大倍数 |
| 涨跌停异动 | 封涨停 / 封跌停 |

- **边界穿越防重复**：阈值附近抖动不误触发
- **除权除息校正**：识别复权因子并把触发价换算到当前口径，避免除权跳空误触发
- **涨跌停独立判定**：覆盖「一字板价格被封住不再变动，导致价格穿越类提醒永久失效」的场景

### 复盘统计（差异化能力）
- 记录每次触发后 30 分钟的实际走向与涨跌幅
- 自动推导「预期方向」（向上突破→预期涨），无需手动标注
- 输出方向胜率、平均涨跌、最佳/最差，按规则类型分组
- 量比与涨跌停无方向性，不计入胜率

### 稳定性
- 交易时段智能调速：0.3s / 0.2s / 0.15s（随阈值接近度切换）
- 数据源失败时指数退避（1s → 60s 封顶），成功即恢复
- 真实交易日历 + 休市降频，避免节假日空转
- K线源 5 层抗风控：串行队列 / 最小间隔 / 域名轮换 / 结果缓存 / 指数退避
- 脏数据全面防御：存档损坏、字段缺失、极端数值均不会导致崩溃

### 界面
- Canvas 迷你走势图（前复权 K线）
- 顶部大盘概览（上证、深证、创业板、沪深300、科创50）
- 搜索联想、热门标的快捷添加、分类筛选
- 桌面通知 + Web Audio 提示音 + 卡片高亮
- 数据保存在浏览器 localStorage，支持导出 JSON 备份
- **演示模式**：无需真实行情也能完整体验

## 🚀 运行说明

### 环境要求

- **浏览器**：Chrome / Edge / Firefox 等现代浏览器（需支持 ES6+）
- **网络**：需能访问公网行情接口
- **无需**：Node.js、npm、任何构建工具、后端服务

### 方式一：直接打开（最简单）

下载源码后，**双击 `index.html`** 即可使用。

> 已实测 `file://` 协议下功能正常，包括行情获取、走势图绘制、提醒触发。

### 方式二：本地服务器（推荐）

部分浏览器对 `file://` 协议有安全限制，若直接打开遇到问题，用本地服务器：

```bash
# 任选一种，在项目目录下执行
python -m http.server 8899      # Python
npx serve .                     # Node.js
php -S localhost:8899          # PHP
```

然后浏览器访问 <http://localhost:8899>

### 首次使用

1. 在顶部搜索框输入代码或名称（如 `600519` 或 `贵州茅台`），回车添加
2. 点击卡片右下角 `+ 添加提醒` 设置规则
3. 点击卡片上的 `ⓘ` 查看详情（含走势图、涨跌停价、复权因子等）
4. 点击右下角 `+` 按钮可一键添加热门标的
5. 点击顶部 🔔 图标授权桌面通知（可选）
6. 点击「异动日志」旁的 `📊 复盘` 查看历史提醒的准确性统计

没有真实行情时，点击顶部「🎮 演示模式」体验完整功能。

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/⌘ + N` | 聚焦搜索框 |
| `Ctrl/⌘ + R` | 立即刷新行情 |
| `Ctrl/⌘ + L` | 清空异动日志 |
| `Ctrl/⌘ + E` | 导出数据为 JSON |
| `Esc` | 关闭弹窗 |

## ⚠️ 数据源说明（重要）

本工具依赖**免费公开行情接口**，存在客观限制，请知悉：

| 限制 | 说明 |
|------|------|
| 接口可能变更或失效 | 免费接口无稳定性承诺，已实现多源切换与降级 |
| 存在风控限流 | 接口按请求频率限流，已实现缓存与退避；封禁期间走势图会显示「走势数据暂不可用」提示 |
| 数据有延迟 | 免费接口通常为延迟行情，**不适合作为交易决策的唯一依据** |
| 部分功能依赖单一源 | 走势图与复权因子依赖腾讯 K线接口，该接口受限时相关功能降级 |

## 🛠 技术说明

- **零依赖**：不使用任何前端框架或第三方库，纯原生 HTML / CSS / JavaScript
- **单页应用**：全部逻辑在 `app.js`，无构建步骤
- **跨域处理**：通过 script 标签注入读取行情

### 数据口径（均经实测验证，非推测）

| 项目 | 口径 | 验证方式 |
|------|------|---------|
| 成交量 | 内部统一为「股」 | 均价 = 成交额÷成交量 ≈ 现价，实测偏差 0.42% |
| 成交额 | 内部统一为「元」 | 同上 |
| 涨跌停价 | 接口直接提供 | 与「昨收×涨跌幅限制」交叉验证 |
| 复权因子 | 后复权收盘 ÷ 前复权收盘 | 偏离 1 即说明区间内有分红送转 |
| 交易日历 | 有K线的日期即为交易日 | 正确识别全部 25 个法定休市日 |
| 量比 | 当日累计量 ÷ 过去5日日均量 | 与第三方接口同值吻合 |
